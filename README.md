Let's Learn & Build Together

Hey everyone! 👋

I'm a beginner developer, and I'm looking for a few people who are also learning programming and want to make some friends, learn together, and build projects together.

I'm not an expert or a mentor — I'm learning too. 😄

I thought it would be more fun to learn with other people instead of doing everything alone.

💡 What I'm looking for

I'd love to meet people who:

👨‍💻 Are beginners or junior developers
📚 Are currently learning programming
🤝 Want to make friends with other developers
💻 Want to work on small projects together
🧠 Don't mind learning from each other
🚀 Want to improve together over time

You don't need to be really good.

I'm not looking for experienced developers. I'm looking for people around my level who want to learn together.

🛠️ What could we do together?

We can figure this out together!

Maybe we could:

Build small projects
Learn Git and GitHub together
Help each other when we're stuck
Share things we've learned
Work on a bigger project after getting to know each other
And most importantly, have fun while learning

There doesn't have to be a perfect plan from day one.

We can start with a few people, get to know each other, and decide what we want to build.

👋 A little about you

If you're interested, just open an Issue and tell us a little about yourself:

Your name or nickname
What you're currently learning
Your programming language(s)
How long you've been learning
What kind of projects you'd like to build
Your GitHub profile

No need to write anything formal.

Just say hi and tell us a little about yourself. :)

❤️ Why I'm making this

Learning programming alone can get boring sometimes.

I'd really like to find some people who are at a similar stage, become friends, help each other, and see where we can go from there.

I'm a beginner too. Let's figure it out together. 🚀
